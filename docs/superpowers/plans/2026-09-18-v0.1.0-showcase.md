# VeritasMed v0.1.0 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Track progress below.

**Goal:** Deliver a reproducible local research showcase with truthful metrics, a functioning evidence-to-answer workflow, and clear release boundaries.

**Architecture:** Keep the existing FastAPI/React/LangGraph/BGE/Qdrant stack. Ask always runs the full agent; Explorer retains P2/P3 retrieval comparison. A small explicitly labelled demonstration corpus is separate from the user's research corpus. Historical evaluation artifacts remain immutable; a deterministic report summarizes them with corrected metrics and failure denominators.

**Tech Stack:** Python 3.12, React/TypeScript, Node 22, LangGraph, Qdrant, Docker Compose.

**Spec:** `docs/milestone-audit-2026-09-18.md`, accepted by the user's request to plan and complete this version.
