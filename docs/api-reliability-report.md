# API reliability validation (v0.1.0)

The ask WebSocket now runs the full LangGraph agent for every request. The legacy `pipeline` input is accepted for compatibility and marked deprecated in the request model; it does not select a route. LangGraph `tasks` events supply node starts before execution, while `updates` supply node completion data. The event names remain `node_start`, `node_end`, `chunk_retrieved`, `done`, and `error`.

The response queue holds at most 32 events, and the request has a 300-second response deadline. A worker exception, final-state failure, or deadline emits `error` without `done`; exception details are logged server-side and omitted from the client message. Disconnects set a cooperative stop flag so the worker stops at the next LangGraph stream boundary. An in-flight synchronous node or remote LLM call cannot be interrupted by this flag. Task 2 separately bounds LLM requests.

Each Ask invocation uses a fresh internal checkpoint UUID. The stable `thread_id` sent by the UI is returned in the answer, but it no longer selects a shared LangGraph checkpoint. This prevents a later question from inheriting additive rewrite/history state and prevents overlapping requests from reading each other's final answer. The release treats Ask as single-turn; the history endpoint keyed by the public thread label cannot retrieve these isolated request checkpoints.

`/api/health` reports `ok` only when the selected LLM backend and Qdrant collection both respond successfully. HTTP 401 is disconnected. The Ollama probe uses `OLLAMA_HOST` and `/api/tags`; the MiMo probe uses its configured OpenAI-compatible `/models` endpoint. `/api/live` checks only that the API process can respond. Readiness does not prove that the selected model is loaded or that a full question can succeed.

Regression tests were written before implementation. Initial targeted run: **7 failed, 2 passed**, with failures for malformed claims, citation normalization, worker failure terminal event, timeout terminal event, MiMo 401, Ollama host selection, and missing liveness. The real-node start test and legacy input test already passed. After implementation, an additional disconnect-between-nodes test passed. Independent review then found shared-checkpoint defects. Two new real-LangGraph regressions reproduced them (**2 failed**): a repeated UI thread inherited old rewrites, and overlapping requests returned the later request's answer. With per-request checkpoint isolation, the final targeted run using `.venv-release/Scripts/python.exe` was **12 passed**, with one upstream Starlette/AnyIO deprecation warning (`pytest -q tests/test_api.py tests/test_citations.py`, `PYTHONPATH=src`, temporary `MEDRAG_DATA_DIR`). Ruff passed on the updated Ask route and API test file.

No external LLM or Qdrant service was contacted by these tests. The checkpointer and graph used for WebSocket tests were local, with controlled node functions. The global test suite, live model calls, and container health integration are separate release gates.
