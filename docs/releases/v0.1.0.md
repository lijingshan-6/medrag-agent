# VeritasMed v0.1.0 — local research showcase

This milestone turns the existing research implementation into an inspectable portfolio project: a clearly labelled no-key interface tour, a separate real retrieval demo, a documented agent workflow, reproducible offline checks and an honest historical evaluation report.

## Included

- React answer / trace / evidence interface with source context and export actions.
- BGE-M3 hybrid search, BGE reranking and bounded LangGraph query/answer correction.
- Request-isolated state and robust stream failure handling.
- Three authored demo passages with provenance; no original research corpus or model weights.
- CPU dependency lock, CI definition, corrected historical metrics, screenshots and a step-by-step walkthrough.

## Release boundary

This is suitable for a **GitHub research showcase with its limitations visible**. It is not a clinical product or public multi-user service. Questions are single-turn; UI session labels do not restore answer history. Guided answers are fixtures and must not be represented as live generation results.

The historical strict set contains 50 attempts, 49 scores and one error: composite 0.671155 on scored questions or 0.657732 counting the error as zero. The separate hard set scored 0.817949 on 39 questions. These are different datasets, not a before/after improvement. See the [full evaluation report](../evaluation_report.md).

## Validation and remaining gates

See the dated [validation record](../validation-2026-09-18.md) for exact checks. In this environment real indexing, reranked retrieval, document access and browser interactions were exercised. The existing MiMo key returned 401, so a successful live generated answer is still an external acceptance gate. Docker Engine was unavailable; container startup and Ollama inference remain unverified. GitHub Actions needs its first hosted run after pushing.

Before advertising a fully live demo, verify a successful question, a synthesis question and an insufficient-evidence question with valid model access. Before promoting Docker instructions to a verified path, build and start the stack on a fresh host. A future research release should freeze the corpus, prompts and judge and compare plain RAG with the agent on the same questions.

This working tree is on `milestone/v0.1.0-showcase`. Source packaging does not create a Git tag, commit, hosted deployment or GitHub Release.
