# VeritasMed v0.2.0 — benchmark-backed showcase

VeritasMed v0.2.0 turns the existing medical-literature RAG demo into an inspectable research showcase. It keeps the guided browser demo, runs the real LangGraph Agent with local Ollama, and adds a source-disjoint benchmark whose labels and disagreements can be audited item by item.

## What is included

- A browser-only Guided mode that starts with Node.js and clearly labels its authored fixtures.
- A Live mode with BGE-M3 retrieval, Qdrant, BGE reranking and the LangGraph retrieve–grade–rewrite–generate–check loop.
- `qwen3.5:9b` as the active local model default. The obsolete `qwen3:8b` default is no longer used.
- VeritasMed benchmark v1.1: 50 questions from 44 PubMed sources across 20 domains, split into 15 development and 35 test questions with no shared source or evidence chunk.
- Exact evidence spans, answerability contracts, model review logs, source-first curator decisions, runtime manifests and saved development outputs.

## Development baseline

The production Agent was run on development only. The test split remains untouched.

| Metric | Result |
|---|---:|
| Required-claim Recall@5 | 0.8846 |
| All required claims found@5 | 0.8462 |
| nDCG@5 / MRR@5 | 0.8933 / 0.9231 |
| Claim completeness | 0.9000 |
| Claim-support precision | 1.0000 |
| Citation coverage | 0.9000 |
| Answerability | 0.8000 |
| Strict pass | **5/15** |
| Mean end-to-end latency | 85.1 s |

The Agent's internal checker marked 15/15 answers faithful, while source-first scoring passed only 5/15 strictly. The saved failure analysis shows the current development priorities: preserve required numerical and cohort qualifiers, retrieve both sides of cross-document questions, and refuse comparative claims when only adjacent evidence is available.

## Quick start

For the interface-only walkthrough:

```sh
cd frontend
npm ci
npm run dev
```

Open `http://127.0.0.1:5173/?demo=1`.

For local Live mode, install the locked Python environment from the root README, start Ollama, then:

```sh
ollama pull qwen3.5:9b
python scripts/run_demo.py
```

See the [demonstration guide](../demo.md) for environment variables and the optional Docker configuration.

## Scope and limits

This is an engineering showcase, not a clinically validated assistant. The benchmark is curator-reviewed rather than clinician-reviewed, its 2026 source snapshot is narrow, and most evidence is abstract-level. Guided answers are authored fixtures. The web API is local and has no public-user authentication or multi-tenant isolation. Docker, the MiMo cloud path and macOS/Linux execution are not signed off in this release.

This file documents a local release candidate. Creating a Git tag, pushing the branch or publishing a GitHub Release are separate actions.
