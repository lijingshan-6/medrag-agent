# v0.3.0 local showcase candidate

This milestone improves the production Agent and makes its measured behavior easy to inspect.
The complete 15-question development run reached **10/15 strict passes**, up from 5/15,
with all required evidence retrieved on 13/13 answerable questions. Mean latency was 91.3 s.

The repository includes the real answers, per-answer source-first decisions, an evidence
walkthrough and a Pydantic-only command to recompute metrics. The guided UI remains available
for a quick browser tour; the README now shows the locally exercised Ollama setup directly.

Two unsupported or incorrectly scoped additions remain. The zero-unsupported-claim target
was not met; all five strict failures are documented. Results are development-set measurements,
not clinician validation. The 35-question test split remains unused.

Verification: 150 Python tests passed, Ruff passed for the changed Python scope, and saved
metrics were recomputed in a fresh environment containing only Pydantic and its dependencies.
No frontend behavior changed in this milestone; existing guided screenshots remain labelled
as authored fixtures. The full benchmark run completed successfully; a nonfatal Qdrant
destructor warning occurred during interpreter shutdown after the result file was saved.

See the [full report](../agent-v0.3-report.md), [15 cases](../agent-v0.3-cases.md),
[workflow](../agent-workflow.md), and [demo guide](../demo.md). This is a local candidate;
no GitHub release, remote push or tag was created by this work.
